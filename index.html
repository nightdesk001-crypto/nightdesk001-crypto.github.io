moshimo-upload

Developed with YouTube

moshimo-upload is a personal tool used only by the owner of the YouTube channel 「もしも検証ラボ」(@moshimo_zundalabo). It uses the YouTube API Services to upload videos that the owner created to the owner's own channel once a day, and to set their title, description, tags and thumbnail. It is not offered to any other users.

YouTubeチャンネル「もしも検証ラボ」の運営者が、自分で作った動画を自分のチャンネルにアップロードするための個人用ツールです。YouTube API サービスを利用しています。他の人には提供していません。

Privacy Policy / プライバシーポリシー

Last updated: 2026-11-10

1. Use of YouTube API Services

This tool uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

本ツールは YouTube API サービスを利用しています。利用者は YouTube 利用規約 に従うものとします。Google によるデータの取り扱いは Google プライバシーポリシー をご覧ください。

2. Information accessed

  • Basic information of the authorized channel (channel name, uploads playlist).
  • List and status (public / private) of videos uploaded to that channel, to avoid duplicate uploads.
  • OAuth access / refresh tokens issued by Google.

許可されたチャンネルの基本情報、アップロード済み動画の一覧と公開状態(二重投稿の防止のため)、Googleが発行する認証トークンを扱います。

3. How information is used, stored and shared

  • Information is used only to upload the owner's videos and check their status.
  • OAuth tokens and logs are stored only on the owner's local PC. Nothing is sent to any server other than Google's APIs.
  • No information is sold or shared with third parties. No cookies or tracking are used by this tool or this website.

情報は動画のアップロードと状態確認のためだけに使います。認証トークンと記録は運営者のパソコン内にだけ保存し、Google の API 以外には送りません。第三者への提供・販売はしません。本ツールと本サイトは Cookie やトラッキングを使いません。

4. Revoking access and deleting data

  • Access can be revoked at any time from the Google security settings page.
  • When access is revoked, the stored token is deleted from the local PC. Stored API data (video list cache) is refreshed or deleted within 30 days.
  • You may also request deletion by contacting us (see below); we will delete it within 7 days.

アクセスは Google のセキュリティ設定ページ からいつでも取り消せます。取り消した場合、保存しているトークンはパソコンから削除し、APIから得たデータは30日以内に更新または削除します。下記の連絡先から削除を依頼することもでき、7日以内に削除します。
